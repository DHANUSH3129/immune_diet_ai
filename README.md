# 🛡️ Immune Diet AI — AI-Powered Personalized Nutrition App

A modern AI-powered immunity nutrition mobile application built using **Flutter + Firebase**.  
The app helps users improve their health through personalized meal planning, immunity tracking, AI-based nutrition guidance, and health report analysis.

---

## 🚀 Features

- ✅ Firebase Authentication (Login / Register)
- ✅ Personalized 7-Day AI Meal Plans
- ✅ Immunity Score Tracking
- ✅ AI Nutrition Assistant Chat
- ✅ Firestore Database Integration
- ✅ Health Report Upload & Analysis
- ✅ BMI Calculation
- ✅ Daily Streak Tracking
- ✅ Nutrient Progress Visualization
- ✅ Session Restore & Persistent Login
- ✅ Clean and Modern Flutter UI

---

## ⚙️ Setup Guide

### 1️⃣ Install Flutter

```bash
flutter doctor
```

### 2️⃣ Install Dependencies

```bash
flutter pub get
```

### 3️⃣ Configure Firebase

```bash
flutterfire configure
```

> This generates `firebase_options.dart` automatically.

---

### 4️⃣ Run the App

```bash
flutter run
```

---

### 5️⃣ Build Release APK

```bash
flutter build apk --release
```

APK output:

```text
build/app/outputs/flutter-apk/app-release.apk
```
